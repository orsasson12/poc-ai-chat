איך החישוב עובד — Key assumptions

  • Token costs: GPT-4o-mini $0.15/M input + $0.60/M output · GPT-4o $2.50/M input + $10/M output · Pinecone $16.50/M reads
  • Per conversation baseline: ~2,000 tokens RAG context × avgTurns + ~200 tokens user input + ~300 tokens output × avgTurns
  • Model routing: miniShare% הולך ל-GPT-4o-mini (שיחות קצרות/פשוטות), השאר ל-GPT-4o (שיחות ארוכות, מתוך lib/llm/)
  • Cache savings: cacheHit% מהcontext נחסך ע"י prompt caching (Anthropic 90% discount) + Redis deduping
  • Overage note: אינו מחושב כאן — כל שיחה מעבר למכסה מחויבת ₪0.15 (margin כ-90%+ כי עלות בפועל ~₪0.04)
  • Pricing: Starter ₪149 · Growth ₪499 · Business ₪1,499 · Enterprise ₪5,000 (ממוצע)
  • מה לא כלול: שכר, שיווק, תשתיות שאינן variable, תמיכה אנושית. זה Gross Margin בלבד.
