# Functional Requirements by Priority

## P0 — MVP Launch Blockers
- FR-01: Signup with email/password or Google SSO
- FR-02: Create assistant with name, greeting, tone, fallback
- FR-03: Upload PDF, DOCX, TXT, CSV (50MB max)
- FR-04: Import URL by pasting
- FR-05: Add manual Q&A pairs
- FR-06: Ingestion pipeline processes within 5 minutes
- FR-07: Real-time ingestion status
- FR-08: Preview assistant in test chat
- FR-09: Copy embed script tag
- FR-10: Widget loads on any website via script tag
- FR-11: Responses grounded exclusively in uploaded content
- FR-12: Configurable fallback message
- FR-13: All five safety layers active
- FR-14: Streaming token-by-token responses
- FR-15: View conversation logs
- FR-16: Pause assistant (single toggle, immediate)
- FR-17: Delete knowledge item (vectors removed <60s)
- FR-18: Stripe billing integrated
- FR-19: WordPress plugin available

## P1 — Ship Within 4 Weeks Post-MVP
- FR-20: Invite team members (Manager/Viewer roles)
- FR-21: Thumbs up/down feedback on responses
- FR-22: Analytics dashboard
- FR-23: Unanswered questions report
- FR-24: After-hours behavior (hide widget / offline message)
- FR-25: Human escalation with transcript

## P2 — Roadmap (Post-Validation)
- FR-26: URL crawler (up to 100 pages)
- FR-27: Shopify plugin
- FR-28: npm/React SDK
- FR-29: REST API with API key auth
- FR-30: Multiple assistants per tenant
- FR-31: OCR for scanned PDFs
- FR-32: Multilingual (Spanish first)
